# CLAUDE CODE + HYPERFRAME — MOTION VIDEO PRODUCTION DIRECTION
## Meta Ads 2026 × Andromeda — “The Signal Has Changed”

## ROLE
Act as a senior motion designer, visual storyteller, advertising strategist, and motion-video engineer.

Use the **Hyperframe skill** to build the final video.

This is NOT a generic animated-text reel. Build a visual argument from the voiceover. Every important concept must have a deliberate visual counterpart: ad creative, UI card, icon, diagram, flow, map, audience card, signal, ranking/retrieval visualization, or purposeful kinetic typography.

## SOURCE + MASTER TIMELINE
Use the supplied voiceover/audio and the accompanying script file:
`Meta_Ads_Andromeda_Signal_Voiceover_Script.txt`

The **actual audio waveform is the master timeline**.

Do not guess timing from paragraph length. Do not split the script into equal-duration scenes.

Before animation:
1. Inspect the audio and determine exact duration.
2. Analyze speech timing / transcription if the Hyperframe workflow supports it.
3. Map important phrases to actual audio timestamps.
4. Build the scene timeline from those timestamps.
5. Render a preview with audio.
6. Watch the complete preview and correct visual timing.
7. Render the final only after sync QA passes.

The video must end exactly with the voiceover. Never stretch, cut, or speed-change the supplied voiceover.

## SYNC RULE — NON-NEGOTIABLE
The viewer must feel that the visuals are reacting to the speaker.

For every important phrase:
- identify its real audio start/end;
- trigger its visual at the appropriate moment;
- keep the visual visible long enough to understand;
- transition only when the narration moves to the next idea.

Never make a visual appear noticeably before the phrase that explains it. Never leave a previous concept on screen after the narration has clearly moved on.

Example:
Voice: “Targeting শেষ।” → visual shows the “TARGETING” concept.
Voice: “আমি কিন্তু এভাবে বলব না।” → visual immediately changes/contradicts the oversimplification.
Voice: “retrieval layer” → retrieval diagram begins at that phrase.

## TECHNICAL ACCURACY
When showing retrieval layer, GEM, foundation models, ranking, user activity, creative representation and interaction signals, use **conceptual/simplified diagrams**.

Do not pretend to reveal Meta’s proprietary internal architecture.

Where necessary, use a small label such as:
`CONCEPTUAL FLOW`
or
`SIMPLIFIED MODEL`

Do not invent technical claims, metrics, ROAS, conversion rates, or proprietary system details.

## ASSET-FIRST RULE
Do NOT begin by animating text and then decorating it.

For each scene decide:
1. What is the primary visual object?
2. What supports it?
3. What does it do when the phrase is spoken?
4. Why does that animation communicate the idea?

Examples:
- “creative” → actual ad creative card, not only the word CREATIVE
- “audience” → audience/persona card
- “conversion signal” → conversion event/pipeline
- “retrieval” → candidate pool entering a retrieval layer
- “ranking” → candidates being ordered
- “real estate” → premium property creative
- “location” → map/location visual
- “offer” → offer/payment-plan card
- “data” → signal stream/data chips

## MOTION LANGUAGE
Use:
- smooth easing
- controlled spring
- subtle scale
- masked reveals
- directional movement
- branching flows
- card stacking
- morphing transitions
- subtle parallax
- continuous camera movement where useful

Avoid:
- random wipes
- spinning objects
- excessive bounce
- glitch overload
- random particles
- unnecessary camera shake
- flashy transitions without narrative reason

## GLASSMORPHISM
Use selectively for:
- audience cards
- signal chips
- creative cards
- system panels
- data cards
- CTA cards

Style:
dark translucent surface + subtle blur + thin ivory border + soft shadow + restrained highlight.

Do NOT make every element glass.

## CREATIVE CARD REQUIREMENT
Whenever the script says “creative”, show an actual ad creative:
property image + headline + offer/message + CTA.

For example:
Investment creative → property + investment headline
Family creative → home/living visual + family headline
Location creative → map + commute headline

Do not represent “creative” only as the word CREATIVE.

## ICON SYSTEM
Use one consistent minimal line-icon family:
target, user, home, location, click, conversion, database, signal, creative, AI/system, ranking, filter, graph.

## TEXT RULE
Do not convert every sentence into giant typography.

Use:
- HERO: 1–5 words
- SUPPORT: short phrase
- MICRO LABEL: small UI label

Most of the story must be carried by actual objects and diagrams.

## BENGALI + ENGLISH

“Targeting শেষ”

“Conversion Signal”
“Business Objective”

- generous spacing

- no tiny paragraphs
