# FAHAD --- PERSONAL BRAND INTRO

## VIDEO DIRECTION / CLAUDE MASTER EDITING BRIEF

### 1. CORE OBJECTIVE

Create a premium personal-brand introduction video for **Fahad**,
positioned as an experienced **Digital Marketing / Business Growth
professional**, not as a generic Facebook Ads specialist.

The video must feel: - Premium - Modern - Intelligent - Futuristic but
believable - Editorial - Data-driven - Human - Minimal and sophisticated

The visual storytelling must communicate one central idea:

> **Fahad does not simply run ads. He thinks about the complete growth
> system behind a business.**

Do not make the video look like a generic AI advertisement, SaaS promo,
crypto video, gaming edit, or "tech bro" reel.

------------------------------------------------------------------------

## 2. SOURCE OF TRUTH --- VERY IMPORTANT

Use the attached ElevenLabs voiceover as the **absolute timing source**.

Approximate total duration: **01:38.5**

The voiceover itself must NOT be rewritten, re-recorded, shortened, sped
up, or rearranged.

Every visual transition, text animation, infographic, icon movement,
graph, flow chart and scene change must be timed to: 1. spoken words, 2.
natural pauses, 3. emphasis, 4. sentence completion.

Do NOT force visual cuts every 1--2 seconds. Some scenes should breathe
for 3--6 seconds when the idea requires it.

Use the voiceover waveform / audio markers to place edit points.

------------------------------------------------------------------------

# 3. BRAND VISUAL SYSTEM

### Background

The dominant background should be a **warm cream / soft ivory**, NOT
pure white.

Primary background: - Soft Ivory / Warm Off-White: **#FBFCEB**

Optional subtle background variation: - Very light warm ivory - Soft
cream - Extremely subtle ivory gradient

The background must remain bright, clean and premium.

### Brand accent palette

Use these colors for typography, lines, diagrams, cards, highlights and
UI elements:

-   Burgundy Red: **#720013**
-   Deep Maroon: **#2D0001**
-   Wine Red: **#3F1521**
-   Crimson Red: **#80011F**
-   Soft Ivory: **#FBFCEB**

### Color rule

Do NOT fill the entire video with dark maroon.

The visual hierarchy should be:

**Warm Ivory Background → Burgundy/Maroon Typography → Crimson
Highlights → Soft Glass Elements**

This keeps the personal brand recognizable without making the video
visually heavy.

------------------------------------------------------------------------

# 4. VISUAL LANGUAGE

Use a sophisticated combination of:

### A. Liquid Glass

Use tasteful liquid-glass / frosted-glass UI elements.

Examples: - translucent glass cards - rounded information panels -
subtle blur - soft inner highlights - glass chips - transparent data
panels - floating metric cards - glassmorphism overlays

Glass should be subtle and elegant.

Avoid exaggerated shiny glass, rainbow glass, Apple-copy visuals, or
excessive reflections.

### B. Infographics

Use custom-built infographics instead of stock visuals.

Examples: - funnel diagrams - customer journey maps - lead flow -
conversion flow - data streams - campaign dashboards - connected nodes -
business growth loops - simple bar/line charts - signal pathways

### C. Flow Charts

Use animated flow systems such as:

**Strategy → Audience → Creative → Campaign → Lead → Qualification → CRM
→ Revenue**

and later:

**Data → Insight → Decision → Optimization → Growth**

The arrows should animate progressively as the voiceover explains the
concept.

### D. Futuristic Elements

Use: - subtle grid systems - thin data lines - small nodes - micro UI
labels - signal pulses - floating data particles - thin circular rings -
minimal dashboard fragments

Keep these elements understated.

This is a **business-growth brand film**, not a sci-fi movie.

------------------------------------------------------------------------

The viewer should feel:

**"This person understands how marketing connects to business."**

**"This person knows how to make flashy AI videos."**

visual noise.

Think:

**McKinsey / premium consulting presentation / modern product film /
high-end personal brand**

combined with:

**Futuristic glass UI + data visualization + editorial motion design.**

------------------------------------------------------------------------

# 27. FINAL MASTER RULE

When there is a conflict between visual beauty and voiceover clarity:

**VOICEOVER CLARITY WINS.**

When there is a conflict between visual complexity and brand
credibility:

**BRAND CREDIBILITY WINS.**

When there is a conflict between adding another effect and keeping the
frame clean:

**KEEP IT CLEAN.**

The finished video should feel premium, intelligent, confident, modern
and trustworthy.

It should look like the beginning of a serious personal brand --- not a
generic promotional reel.
